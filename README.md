## Features

- **Responsive Design:** Optimized to look great on desktop, tablet, and mobile devices.
- **Interactive Elements:** Smooth navigation, dynamic project cards, or interactive contact links.
- **Showcase Sections:** Dedicated areas for professional summary, core technical skills, featured projects, and social links.
- **Lightweight & Fast:** Built without heavy frameworks for optimal loading speed.

---

## Project Structure

```text
├── index.html        # Main HTML structure and content
├── style.css         # Custom styling, layout, and responsive media queries
├── script.js         # Interactive features and dynamic behavior
└── assets/           # Images, icons, and media files
```
